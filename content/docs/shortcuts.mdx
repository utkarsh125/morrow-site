---

## Key Bindings

| Shortcut | Action | Description |
| :--- | :--- | :--- |
| `Ctrl-S` / `Ctrl-Enter` | **Send Message** | Submit prompt with streaming response |
| `Enter` | **Newline / Execute** | Insert newline (or execute slash command) |
| `Tab` | **Autocomplete / Indent** | Accept slash command suggestion or indent |
| `Ctrl-N` | **New Session** | Start a clean conversation thread |
| `Ctrl-H` | **History Browser** | Search, preview, rename (`r`), delete (`d`) sessions |
| `Ctrl-T` | **Theme Browser** | Open 65+ Kitty themes modal with live preview |
| `Ctrl-P` / `Ctrl-M` | **Model Switcher** | Open fuzzy model picker |
| `Ctrl-B` | **Toggle Sidebar** | Show or hide conversation sidebar |
| `Ctrl-Y` | **Copy Response** | Copy last response to system clipboard (OSC 52) |
| `PgUp` / `PgDn` | **Page Scroll** | Scroll chat history viewport |
| `Ctrl-U` / `Ctrl-D` | **Half Scroll** | Vim-style half-page up and half-page down |
| `Up` / `Down` | **Input History** | Recall sent prompts or navigate modal lists |
| `Esc` | **Dismiss** | Close active modal, cancel autocomplete, or clear |
| `Ctrl-C` | **Abort / Quit** | Cancel active generation stream or exit Morrow |
